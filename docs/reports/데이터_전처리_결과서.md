# 데이터 전처리 결과서

## 1. 데이터 개요

- **데이터셋명:** OkCupid Profiles
- **출처:** [Kaggle — OkCupid Profiles Dataset](https://www.kaggle.com/datasets/andrewmvd/okcupid-profiles/data) (2012년 6월 수집 / 샌프란시스코 베이에어리어 반경 25마일 / 영어 사용자)
- **행 수:** 59,946
- **열 수:** 31 (원본) → 파생 생성 후 최종 입력 20개
- **Target:** `churn_suspect` — 기준 시각(2012-07-01 09:00) 대비 **30일 이상 미접속** 시 1

원본 데이터에 이탈 여부 컬럼이 존재하지 않아 `last_online`을 활용한 대리 라벨(proxy label)을 생성했다. 기준 시각은 데이터 내 가장 최근 접속 기록(2012-07-01 08:57) 직후인 09:00으로 설정해 수집 종료 시점을 기준으로 삼았다. 임계값은 아래 분포를 확인해 30일로 결정했다.

| 기준 | 이탈 비율 | 인원 |
| --- | --- | --- |
| 7일 | 40.5% | 24,277 |
| 14일 | 32.7% | 19,604 |
| **30일** | **25.7%** | **15,419** |
| 60일 | 19.6% | 11,752 |
| 90일 | 15.4% | 9,245 |
| 180일 | 8.0% | 4,788 |

7·14일은 단순 휴면 사용자까지 이탈로 분류할 위험이 크고, 90·180일은 양성 클래스가 지나치게 희소해진다. 최종 모델에서는 30일을 기준으로 사용했으며, 전체 데이터의 이탈 의심 비율은 **25.72%**다.

## 3. 데이터 분리

- **분할:** Train 44,959 (75%) / Test 14,987 (25%). stratify를 적용해 두 세트 모두 이탈 의심 비율 25.72%
- **검증 방식:** 고정 Valid 세트 없이 Train 내부 Stratified K-Fold 교차검증
- **재현성:** seed 42 (분할은 팀 공통 시드 고정 함수 `reset_seeds`, `StratifiedKFold`는 `random_state=42`)
- **선분리:** 타깃 생성 직후 Train/Test를 먼저 나누고 `feature_extraction()`을 각각 적용했다. 행 단위 결정적 변환이라 전체 데이터 통계량을 fit하는 인코더·스케일러는 없다.
- **Test 사용 범위:** 최종 교차검증과 하이퍼파라미터 탐색에는 사용하지 않았고, 모델 비교와 Feature 추가·축소(25개 → 20개) 단계에서는 Test 성능을 참고했다(영향은 학습 결과서 8절 참고).

## 4. 결측치 처리

이 데이터에서는 결측 자체가 "응답하지 않았다"는 정보다. 실제로 `offspring` 무응답 집단의 이탈 의심 비율이 응답 집단보다 높았기 때문에, 중앙값·최빈값으로 일괄 대체하지 않고 **범주형은 별도 범주로 보존, 수치형은 NaN 유지** 방향을 택했다.

| 컬럼 | 결측 비율 | 처리 방법 | 처리 이유 |
| --- | --- | --- | --- |
| 범주형 9개 전체 | 0\~78% | `not_disclosed` 별도 범주로 지정 | 미응답을 기존 범주에 흡수하지 않고 독립적인 정보로 유지 |
| `has_kids` | 59.14% | `no` / `yes` / `unspecified` / `not_disclosed` 4범주 | 자녀 질문에 응답했으나 유무를 명시하지 않은 경우와 완전 무응답을 구분 (Train: 12,159 / 3,720 / 2,489 / 26,591) |
| `has_kids_na` | — | 무응답 여부 0/1 플래그 신규 생성 | 무응답 집단 이탈 의심률 **31.92%** vs 응답 집단 **16.74%** |
| `income` | 80.85% | -1 → NaN 변환 후 결측 유지 | -1은 실제 소득이 아닌 미공개 코드이므로 수치값으로 학습하지 않음 |

## 5. 중복 / 이상치 처리

- **중복:** 원본 31개 컬럼 기준, essay 10개 컬럼을 제외한 기준 모두 `duplicated().sum()` = **0건**이라 제거 작업은 하지 않았다.
- **이상치:** Train 수치형 `describe()`로 점검했다.

| 컬럼 | 발견 | 처리 | 이유 |
| --- | --- | --- | --- |
| `age` | 최댓값 110세 | 18세 미만·90세 초과 → NaN (전체 2행, 109세·110세) | 비현실적인 값만 결측으로 바꾸고 행은 유지 |
| `income` | 최솟값 -1 | -1 → NaN (Train 36,350행) | -1은 실제 소득이 아닌 미공개 코드 |
| `height` | 최솟값 1인치·최댓값 95인치 | 처리하지 않음 (55인치 미만 39행, 85인치 초과 34행) | 전체의 약 0.12%(73행)로 적고, CatBoost는 값의 대소 순서로만 분기해 영향이 제한적 |

## 6. 인코딩 · 스케일링

- **인코딩:** 범주형 9개는 별도 인코더 없이 `category` dtype으로 지정해 CatBoost `cat_features`로 직접 전달했다(팀 공통 모델링 모듈 `MeowModeling`이 비수치형 컬럼을 자동 탐지). `job` 21종, `edu_level` 8종, `religion_type` 9종처럼 범주가 많은 컬럼이 있어 One-Hot 대신 CatBoost의 내부 범주형 처리를 사용했다.
- **스케일링:** 적용하지 않았다. 트리 기반 모델은 선형 스케일 변환으로 분기 순서가 바뀌지 않으므로, `age`와 `essay_total_words`처럼 범위가 다른 Feature가 섞여 있어도 스케일러가 필요 없다.

## 7. Feature Engineering / 제거 컬럼

### 생성·변환한 Feature

| 항목 | 처리 내용 | 근거 |
| --- | --- | --- |
| Essay 문자열 정리 | `essay0`\~`essay9`에 `html.unescape()` 적용 후 `.`, `-`, `?`, `_`, `/`, `na`, `n/a` 등 의미 없는 입력을 NaN으로 정규화 | 작성 개수·길이 계산 전에 실제 응답과 빈 응답을 구분 |
| 순서형 변환 | `drugs_level`(0\~2), `smokes_level`(0\~4) | 순서가 있는 범주는 정수 척도로 변환 |
| 복합값 분리 | `diet`→`diet_type`+`diet_strict`, `education`→`edu_level`+`edu_status`, `offspring`→`has_kids`+`wants_kids`, `religion`→`religion_type` | 한 문자열에 섞인 정보를 독립 Feature로 사용 |
| `profile_completeness` | 프로필 17개 항목의 응답 비율 (0\~1), 결측 대체 이전에 계산 | Train 5분위 기준 이탈 의심률 32.29% → 13.20% |
| `has_kids_na` | 자녀 항목 무응답 0/1 | 무응답 31.92% vs 응답 16.74% |
| `essay_count` | 작성한 essay 칸 수 (0\~10) | 0칸 작성 집단 이탈 의심률 58.17%, 1칸 이상 24.51% |
| `essay_total_words` | HTML 태그·연속 공백 정리 후 총 단어 수 | 자기소개 전체 분량 |
| `essay_avg_len` | 응답한 essay의 평균 글자 수 | 한 칸당 작성 밀도. `essay_count`와 상관계수 약 0.004로 겹치지 않음 |
| `essay_len_std` | 응답한 essay 길이의 표준편차 | 여러 칸에 고르게 썼는지, 한 칸에 몰아 썼는지 |

## 8. 클래스 불균형

- **분포:** 이탈 의심(1) 15,419명(25.72%) / 그 외(0) 44,527명(74.28%) → 약 **1 : 2.89**
- **대응:** CatBoost `auto_class_weights="Balanced"`로 학습 시점의 Train 라벨 분포에 맞춰 클래스 가중치를 자동 계산했다. 데이터를 합성하는 SMOTE-NC는 모듈에 구현돼 있지만 최종 모델에는 적용하지 않았다.

## 11. 해석상 유의사항

타깃은 수집 종료 시점에 이미 30일 이상 접속하지 않은 사용자를 1로 정의한 대리 라벨이다. 입력 Feature도 같은 시점의 프로필 스냅샷이므로, 이 모델은 엄밀한 의미의 미래 이탈 예측보다는 현재 프로필 특성으로 휴면(이탈 의심) 상태를 판별하는 성격에 가깝다. 실제 탈퇴 여부나 매칭·메시지·접속 빈도 같은 행동 데이터가 없다는 점도 한계다.

또한 데이터가 2012년 샌프란시스코 베이에어리어의 영어 사용자로 한정되어 있어, 다른 지역·시기·플랫폼에 결과를 그대로 일반화하기는 어렵다.
